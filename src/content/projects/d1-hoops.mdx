## What it does

Every morning D1 Hoops ranks tonight's slate by how worth watching each game is, gives each a pregame win probability, and grades yesterday's picks. Behind that are rankings for all 365 teams in four views (ratings, four factors, shooting, résumé), a page per team with its schedule and statistical comps, player leaderboards and profiles with game logs and shot diet, a matchup simulator for any two teams on any floor, conference standings with projected records, and a methodology page with live calibration.

## The model

DHR v2 is a ridge-regularised, opponent-adjusted rating for offence, defence and tempo, with conference priors, a jointly estimated home edge and a pooled node for non-D-I opponents. Every prediction is walk-forward: it uses only games finished before that game's date, so the backtest is the same thing a reader would have seen that morning. Misses stay on the scorecard.

## More than basketball

The player rankings, chart gallery and chart builder run on a sport-agnostic engine. Each sport is a pack of stats, filters, ranking lenses and charts that a validator checks. College basketball runs on live data; pro tennis, club soccer and college football packs run in the [sport lab](https://shaincarrasco.github.io/D1-Basketball-Analytics/lab/sports/) on clearly fictional sample players until real feeds are wired in.

## How it runs

GitHub Actions pulls season data from College Basketball Data daily, adds ESPN box scores hourly from noon to 4 a.m. Eastern, refits the ratings, and exports a static Next.js site to GitHub Pages. News, previews and injury reports come from a small Rust fetcher. Free to run, free to use.
